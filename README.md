# 🎬 TasteFlicks — Premium Cinematic Tracker

TasteFlicks is a modern web app for tracking, rating, and exploring movies and TV shows with a sleek, cinematic UI experience.

Built using **React, Vite, Tailwind CSS, TanStack Query, and Supabase**, it focuses on performance, visual polish, and gamified user engagement.

---

## ✨ Features

- 🎮 Gamified watch tracking with 365-day activity heatmap and streaks
- 🔎 Unified search with infinite scrolling results
- 🎬 Movie & TV show discovery powered by TMDB API
- 💎 Glassmorphic, responsive UI with smooth micro-interactions
- ⚡ Fast performance using TanStack Query caching
- 🔐 Secure authentication via Supabase

---

## 🧱 Tech Stack

- React + Vite
- Tailwind CSS
- TanStack Query
- Supabase
- TMDB API

## 📁 Project Setup

### Clone the repository

```bash
git clone https://github.com/your-username/tasteflicks.git
cd tasteflicks
npm install
```

### Create .env file

VITE_SUPABASE_URL=your_url
VITE_SUPABASE_ANON_KEY=your_key
VITE_TMDB_API_KEY=your_key

### Run locally:

npm run dev

### Then open:

http://localhost:5173
